## 1. テストレベル

  - 優先順位スコア計算ロジック
  - AI応答パース & コマンド変換

  - 暗号化・復号モジュール
- **統合テスト (Integration Test)**:
  - AI対話 -> ToDo自動生成 -> DB暗号化保存 -> 通知予約の一連フロー

- **実機検証 (Device Integration Test)**:
  - Doze Mode（バッテリー最適化）下でのアラーム精度検証

## 3. Codexレビューで追加した必須ケース
- [ ] 同じタイトルのアラーム2件が独立して発火・取消できる
- [ ] 同一アラームIDの再試行が二重登録にならない
- [ ] Exact Alarm権限なしでクラッシュせず設定画面を案内する
- [ ] 通知権限拒否時に成功表示を出さない
- [ ] 再起動後、未来のアラームだけを一度再登録する
- [ ] 発火済み・期限切れアラームを復旧対象から除外する
- [ ] パッケージ更新後の復旧で二重通知を発生させない
- [ ] 端末時刻・タイムゾーン変更時の期待動作を記録する
- [ ] 暗号化ストレージ破損・鍵消失時に安全に失敗する
- [ ] ログ・画面・例外へ保存値や機密値を出さない

KotlinとFlutterは同一端末・同一OS・同一シナリオで比較する。実機証跡には端末、OS、権限状態、
バッテリー最適化状態、予定時刻、実発火時刻、誤差、アプリ状態を記録する。
